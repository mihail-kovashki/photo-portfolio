# Pass logs

One file per place: how its editorial pass went and why the selection is what it is.
The collection file in `src/data/collections/` holds only the result (order, overrides,
drops); `taste.md` in lr-agent holds only where I corrected Claude. This is the reasoning
in between, written at the end of each pass.

Each log has the source and the mapping to places, Claude's rating for every photo
considered (the stars in the files are the final ones), a line on each selected photo,
the near-duplicate runs and which frame won, and the notable drops.

Seoul 2025 and Seoraksan 2025 were reconstructed afterwards from the conversation:
Seoul's per-photo ratings are lost, Seoraksan's survived.
